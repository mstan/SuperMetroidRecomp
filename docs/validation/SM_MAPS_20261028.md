# Map feature checkpoint, 2026-10-28

Three independent features use the shared, read-only world model:

* **Clear pause map:** dense grid, area colours, door weapon colours/symbols,
  station letters, item rings/dots and one-way arrows. Native scrolling and
  L/R pause tabs remain available.
* **Zebes map:** X opens the world; L/R zoom, D-pad pans, Y centres Samus,
  X/B returns and Start resumes gameplay.
* **Map over gameplay:** Select+Start toggles a compact/wide overlay. Its
  background stays live or pauses offline. Netplay always uses live mode.

No cartridge or save-data writes are involved. Pausing skips the gameplay
step to its own epilogue at `$82:8B47 -> 8BB7`; interrupt/audio service
continues. A composed-picture cache preserves the backdrop. Visible timeline
restores close the transient UI and invalidate that cache. HUD readouts draw
above map panels and yield their space while the full world is open.

Atlas placement follows native exit/arrival geometry, using dotted connectors
for non-aligned passages. Area views retain native map coordinates. Crumble
arrows follow the actual BTS -> PLM -> `$84:CE37` setup; other special blocks
do not become false arrows. There are 408 state-specific markers: 324 PLM
markers plus 84 crumble-floor markers, retaining all 100 unique items.

`tools/test_qol_maps.py` runs seven cases with fresh profiles and muted dummy
SDL audio/video. It captures composed presentation through
`SNESRECOMP_SCREENSHOT`; bare PPU dumps do not establish an overlay appeared.
