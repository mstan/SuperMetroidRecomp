# Quit to file select — 2026-10-28

The independent, opt-in `super-metroid.pacing/quit-to-file-select` feature
adds **Quit to file select** to pause Options. It fades the existing picture
before entering the native Game Over End/soft-reset path, then supplies
Start edges through the input-transform API until native file selection.
It does not write the cartridge or saved progress. The existing final-screen
return remains independent and still waits for the completed ending pose.

The existing pause HLE wrapper owns the fade step. When bypassing the original
pause body, it calls its bare RTS at `$82:90FE`; the preceding PLB cannot be
used because the bank prefix was skipped. The new `$82:89E5` hook finishes
navigation in guest execution, including speculative frames. An attempted
hook inside the HLE-replaced pause body was rejected by generation and removed.

Transition intent is simulation state, included in file snapshots (SMFS 5)
and execution/rollback snapshots (SMEX 6). Invalid stage values are rejected.
Older snapshots are build-specific and intentionally unsupported. SRAM is a
separate contract and is preserved.
