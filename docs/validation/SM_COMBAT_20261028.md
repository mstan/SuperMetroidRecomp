## Auto-charge

`tools/test_qol_auto_charge.py` creates fresh isolated profiles and uses muted,
headless game launches. Its five scenarios cover stock, auto-charge, missing
Charge Beam, native Power Bomb-selected combos and optional Select combos.

* Idle charging produces no bullets and caps at 120.
* Four taps produce charged, normal, normal, charged after waiting. With the
  feature off, or without Charge Beam, all four shots are normal.
* Idle charging consumes no Power Bombs. A full-charge tap with Power Bombs
  selected preserves the native combo: one bomb spent, four projectiles.
* Optional Select combos also work after idle charging without holding Shoot.

Results: `auto-charge-qualified-{aot,interp}/results.json`. Per-frame observed
gameplay fields and all WRAM, SRAM, VRAM, CGRAM, OAM and framebuffer snapshots
are identical across those paths. Actual interpreter instructions in the
auto case rise from 4,759,748 to 4,780,613. The denied root is `$90:B80D`
(including its `$10` alias).

Whole-state traces differ in one earlier frame, 8,125, only in RAM CRC. The
same difference occurs with auto-charge disabled, so it is a shared execution
path discrepancy, not an auto-charge regression. Global bit-exact trace
equivalence is not claimed.

## Tourian

`tools/test_qol_tourian.py` reaches the room with normal door loading, lets
the baby drain Samus naturally to 1 HP, and waits for normal control to return.
Only then is health restored for route protection. No boss or door success
flags are poked. Normal jump/shoot inputs open and traverse both gates:
`DCB1 -> DC65 -> DC19`. The same inputs with the feature off remain in `DCB1`.
Re-entry uses a door-load teleport, exercising the actual state selector.
It selects state `DCDD`, music `1E/5` and population `E28E`; Samus stays alive.
The loaded population exactly matches the nine retained corpse entries.
Live and corpse sidehoppers share an enemy ID, so ID exclusion alone is an
invalid test; the fixture checks the full ordered population and count.

Results: `tourian-qualified-aot/results.json` and
`tourian-qualified-interp-stateflow/results.json`. Per-frame observed fields
and complete WRAM snapshots match. The interpreter target file includes
`A9:F21B`, `84:C794`, `8F:E612`, `82:DEF2` and the room-selector control-flow
unit `8F:E5D2/E5E6`, with aliases.

A narrower mixed-path diagnostic interpreting only the condition routine
failed at the selector's stack-consuming finish path (BRK `$91:E37D`). It is
retained under `tourian-qualified-interp/` as a separate engine boundary
finding, `beads-8wg.2.163`. Interpreting the complete selector control-flow unit passes; this
does not erase the narrower failure or prove every mixed boundary correct.

The previous blocked-door report was a fixture problem: it fired during the
drained pose, before control returned, then approached the portal below door
height. The working fixture waits for pose 2 and jumps again after shooting.
