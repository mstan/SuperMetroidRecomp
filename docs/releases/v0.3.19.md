This stable release brings the approved rendering and memory work to current main.

- The minimap's final dotted border follows the map when the HUD is anchored at the screen edge.
- Windows x64 builds include the qualified shared row planner and native-center reuse. Custom rendering remains opt-in, and unsupported/interpolated cases keep the reference route.
- Compact captured PPU registers reduce renderer stack/storage costs. Scene-export scratch is allocated only for a requested snapshot.
- Released wall, unused-room padding, lava-surface and eye-beam fixes are preserved. Room camera behavior is unchanged.
- Other platforms retain their existing portable renderer defaults. Source build options for row planning and center reuse remain OFF by default.

The owner accepted the presented Metroid candidate. Automated and independent validation cover renderer fixtures, real captured scenes, per-frame full-WRAM CRC/CPU-register traces, current-build save/load and fresh-process restoration. Three matched 5,000-frame widescreen pairs on SERVER (Windows x64) used qualified GCC binaries and 15.4-20.4% less process CPU with row/center options enabled (median 18.8%, NoSpriteLimits=1). The release workflow uses Clang, so this is not a measurement of the downloadable executable. This describes that measured Windows workload; it is not an original-Xbox or universal frame-rate claim, and package percentages are not additive.

The separate v0.4.x enhancement prereleases are unchanged. Keep native SRAM saves and settings when updating. Host save states belong to their exact build. Supply your own supported ROM; downloads contain only the precompiled runtime and assets.
