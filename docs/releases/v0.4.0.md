This prerelease adds forty individually configurable Super Metroid enhancements
to the launcher's Mods page, alongside widescreen and presentation FPS. It also
retains the replay and widescreen fixes from v0.3.18.

- Maps and HUD: clearer pause map with door markers, zoomable world map,
  optional live or paused map overlay, aiming laser, pause statistics and
  maximum ammo capacities. Gameplay keeps the native ammo counters.
- Controls and movement: Zero Mission-style shoulder controls, weapon radial
  selection, respin, momentum preservation, morph movement and shinespark
  options.
- Combat and balance: idle auto charge with tap-to-fire charged shots, item
  magnet, configurable bombs, screw attack improvements, reserve and station
  improvements, and vanilla bug fixes.
- Pacing: intro/Ceres/credits skips, faster elevators and doors, reduced screen
  shake, optional instant pickups and complete pickup-jingle removal, pause
  quit to file select, and return from the completion screen.

Elective enhancements are off by default. Correctness fixes are enabled by
default. Select the features you want in Mods before starting a session.
Inspired features credit the original hack authors in their package descriptions.
These are native runtime features for the supported unmodified ROM; full ROM-hack
packs are deferred. The requested falling aim-down change and suit-transformation
skip are not included pending their definitions.

The feature work passed Windows/Linux unit and targeted gameplay checks,
compiled/interpreted comparisons, stock-behavior checks, matching/mismatching
mod-set netplay checks, and owner playtesting. The final map fades, moving charge
flare and duplicate gameplay ammo row were corrected after that review. Release
packages are built and tested separately for Windows x64, Linux x64, macOS arm64
and macOS x64. This is a prerelease, not a claim of an unassisted full-game audit.
The previously reported Steam Deck audio crackle remains unverified on that device.

Extract the complete package; on Linux use Launch.sh. Supply your own supported
Super Metroid (Japan, USA) ROM. Keep native SRAM saves and settings when updating;
host save states are specific to their exact build. Downloads contain the native
runtime, launcher assets and mod manifests, with no ROM, generated C or saves.
