# Super Metroid 0.4.14

The desktop cursor hides over focused gameplay and reappears for interactive
menus, when the window loses focus, when the pointer leaves the gameplay area,
and during shutdown. Mouse and keyboard gameplay bindings remain unchanged.

Controller selection remembers the saved device model across startup and
applies a different connected gamepad immediately, even when the input source
stays Gamepad. Keyboard and unassigned selections, button mappings and assignments for identical
controllers retain their existing behavior.
