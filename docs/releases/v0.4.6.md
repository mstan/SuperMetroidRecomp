# Super Metroid 0.4.6

OpenGL presentation now clamps the framebuffer at its edges. Linear filtering
no longer blends the bottom row into the top row, or the right edge into the
left edge, when scaling the image. HUD and room pixels remain intact.

The correction also reapplies the normal addressing mode after disabling a
shader preset. Active presets retain their own wrapping rules. Real GPU
readback checks cover nearest and linear filtering, integer and fractional
scaling, and the Direct3D11 reference path on Windows.

Adaptive Fit remains the fresh default. Existing settings and native saves
remain unchanged.
